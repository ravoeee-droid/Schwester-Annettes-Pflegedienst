# JJ Media Website Agent System — Golden Master V4

Binding for all AI-assisted website work. STOP-SHIP quality gate.

Workflow: Research → Facts Ledger → Human-First Creative Strategy → Positioning Thesis → Art Direction → primary/secondary conversion journeys → 3 project-specific Signature Components → Build → Code Review → rendered Desktop QA → rendered Mobile QA → Accessibility/Conversion/Recruiting QA → fix loop → final release review.

Walterhof/Auetal are quality references, never copy-paste templates. Every company must feel individually art-directed. Preserve real branding/assets/facts; never invent people, claims, reviews, benefits or vacancies.

For recruiting, a generic jobs section is insufficient. Build a complete Karrierewelt with employer story/mission, real people and leadership where assets exist, authentic work insights, benefits/reasons to join, vacancies, objections/FAQ, low-friction Schnellbewerbung, emotional candidate journey and repeated contextual CTAs.

Implementation must be premium production-quality Next.js: strong hierarchy, responsive typography, intentional whitespace, relevant imagery, tasteful motion/interactions, accessible semantics/keyboard/focus/contrast/reduced motion and excellent mobile behavior. Avoid generic AI/SaaS layouts, repetitive card grids, meaningless gradients, excessive pills and template-looking sections.

STOP-SHIP if any build/lint/type/runtime error, broken route/link/form/asset, mobile overflow, placeholder or unsupported fact, missing conversion path, incomplete Karrierewelt when recruiting matters, inaccessible critical interaction, inconsistent branding, poor/irrelevant hero imagery, regression, or visual quality below the Golden Master reference remains.

Definition of done — 15k Quality Gate: bespoke premium agency quality, distinctive strategy, strong copy architecture, credible facts, project-specific art direction, meaningful signature components, complete conversion journeys, polished interactions and verified desktop/mobile technical quality. Do not call a site finished merely because it compiles. Do not final-deploy without required approval.
